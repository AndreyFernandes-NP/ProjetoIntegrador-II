# Etapas do Projeto

Este documento substitui um cronograma datado nessa fase.

| Etapa | Conteúdo | Estado documental |
| --- | --- | --- |
| 1. Definição | Problema, objetivo e critérios da triagem | Definido |
| 2. Preparação | Leitura, transformação, validação e Parquet | Implementação trabalhada, revisar versão final |
| 3. Divisão | Treino, validação, teste e controles por imagem | Implementação trabalhada, revisar artefatos |
| 4. Visão | Descrição e score das imagens | Implementação experimental |
| 5. PLN | Sentimento e sinais derivados do texto | Em revisão de features |
| 6. Deep learning | Representação de perfis tabulares | Implementação experimental |
| 7. Fusão | Classificação com dados originais e enriquecidos | Experimentos preliminares |
| 8. Avaliação | Ablação, robustez, generalização e teste final | A consolidar |
| 9. Entrega | Notebook operacional, resultados, apresentação e README técnico | Em produção |

## Critério de passagem entre etapas

Uma etapa só deve ser considerada concluída após revisão de suas entradas, saídas, configurações, métricas e impactos nas etapas posteriores. A descoberta de uma feature inadequada pode exigir retornar à etapa de enriquecimento.
