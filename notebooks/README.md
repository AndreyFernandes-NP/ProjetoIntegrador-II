# Notebooks (`notebooks/`)

Espaço destinado a análise exploratória, visualização de distribuições e protótipos de experimentos. Os notebooks servem para compreender o dataset e investigar alternativas antes da integração ao código principal e em principal, documentar e explicar de forma técnica tudo que foi realizado durante as etapas do projeto.

## Usos previstos

- Examinar equilíbrio das categorias de chamados.
- Investigar textos, dados ausentes e evidências visuais.
- Comparar representações, features e resultados de modelos.
- Produzir gráficos e observações para os relatórios acadêmicos.

## Boas práticas

Experimentos confirmados devem ser reproduzíveis em módulos de `src/` ou acompanhados de parâmetros e dados explicitados. Não alterar o dataset original sem controle de versão nem usar o conjunto de teste para orientar exploração de hiperparâmetros.
